# Task 6 - Mall Customer Segmentation

## 📌 Project Overview

This project focuses on **Mall Customer Segmentation** using Python and Machine Learning. The customers are grouped into different segments based on their **Annual Income** and **Spending Score**.

## 🎯 Objective

The main objective is to identify different groups of customers using **K-Means Clustering** and understand their spending behavior.

## 📂 Dataset

**Dataset:** Mall Customers Dataset

The dataset contains customer information such as:

* Customer ID
* Gender
* Age
* Annual Income
* Spending Score

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## 🔍 Methodology

1. Loaded the Mall Customers dataset.
2. Checked and handled missing values.
3. Performed basic data analysis.
4. Selected relevant features for clustering.
5. Applied **K-Means Clustering**.
6. Visualized the customer segments using graphs.
7. Analyzed the resulting clusters.

## 📊 Result

The K-Means algorithm divided the customers into different groups based on their income and spending patterns. These clusters help understand customer behavior and can support better marketing decisions.

## ✅ Conclusion

Mall Customer Segmentation demonstrates how **unsupervised machine learning** can be used to identify meaningful customer groups from data.
